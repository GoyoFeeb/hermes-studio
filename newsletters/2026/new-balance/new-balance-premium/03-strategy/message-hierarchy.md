# Message Hierarchy: New Balance — new-balance-premium

## Jerarquía de información

```
NIVEL 1 — HERO (lo más importante)
└─ Imagen lifestyle running: atleta real en movimiento
└─ Titular: "The Running Collection"
└─ Subtítulo: "Donde el rendimiento encuentra el estilo"
└─ CTA: "Descubrir"

NIVEL 2 — BLOQUE EDITORIAL 1 (foto + texto)
└─ "Nuevos colores, mismo espíritu"
└─ La colección running se renueva con una paleta fresca
└─ Imagen: producto en contexto lifestyle

NIVEL 3 — BLOQUE EDITORIAL 2 (texto + foto)
└─ "120 años de herencia"
└─ Desde 1906, cada zapatilla cuenta una historia de innovación
└─ Imagen: detalle de producto/artesanía

NIVEL 4 — VALORES DE MARCA (3 pilares)
└─ Rendimiento: tecnología Fresh Foam, FuelCell
└─ Herencia: MADE in USA desde 1906
└─ Estilo: colaboraciones que definen cultura

NIVEL 5 — CIERRE
└─ "We're In It For The Long Run"
└─ CTA: "Descubrir la colección"
```

## Recorrido visual del lector

1. **Hero** → Atrapa la atención con fotografía impactante → establece el contexto editorial
2. **Editorial 1** → Conecta emocionalmente → muestra el producto en uso real
3. **Editorial 2** → Añade profundidad → cuenta la historia de la marca
4. **Valores** → Razones para creer → 3 pilares diferenciadores
5. **Cierre** → CTA final → conversión

## Principio de diseño

Cada módulo *muestra*, no *dice*. La fotografía hace el trabajo pesado; el texto es apoyo, no protagonista.

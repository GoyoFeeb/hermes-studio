# CTA Options — Nike Pegasus 42

## Opción A (recomendada — para hero, intro y cierre)
**"Comprar el Pegasus 42"** → ficha de producto
- Directo. Coherente con el objetivo de dirigir tráfico a la ficha.
- ✅ Verbo de compra aceptable (es producto físico, no financiación)

## Opción B (variante para cierre)
**"Consigue tu Pegasus 42"** → ficha de producto
- Ligeramente menos transaccional
- Adecuado para el cierre si se quiere variar

## Opción C (alternativa)
**"Descubre el Pegasus 42"** → ficha de producto
- Más aspiracional, menos directo
- Adecuado si se prefiere un enfoque de descubrimiento

# Mobile Spec — Nike Pegasus 42

## Reglas generales

- El motor ya tiene `class="mobile-stack"` en card-tarifa-3: en mobile, las 3 columnas apilan verticalmente.
- Padding se reduce vía `class="mobile-pad-sm"`.
- Hero image se escala con `class="mobile-img"`.
- H1 hero se reduce a 22px (`class="mobile-hero-h1"`).
- CTAs usan `class="mobile-full"` para ocupar todo el ancho.

## Ajustes por módulo

Sin cambios específicos manuales — los componentes del motor manejan la adaptación mobile automáticamente.

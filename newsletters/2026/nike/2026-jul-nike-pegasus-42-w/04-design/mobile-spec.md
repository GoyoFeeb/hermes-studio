# Mobile Spec

- Breakpoint: 599px (max-width)
- Todos los módulos apilan verticalmente (mobile-stack)
- H1 hero: 22px (desktop→mobile)
- Subtítulo hero: 14px (desktop→mobile)
- Secciones: padding lateral reducido (mobile-pad-sm)
- Tarjetas de 3 columnas → stack vertical (mobile-stack: cada tarjeta ocupa 100%)
- CTA: full-width en mobile (mobile-full)

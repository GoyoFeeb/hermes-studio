# Asset Specification System — Para y Compara

> Versión 1.0
> No se generan assets. Solo se definen especificaciones.

---

## Hero

| Propiedad | Valor |
|---|---|
| Nombre | `hero-[campaña]-v[versión].png` |
| Ancho | 600px |
| Alto | 320–340px |
| Formato | PNG o JPG |
| Peso máx. | 180 KB |
| Alt | "Compara tarifas de fibra, móvil y televisión con Para y Compara" |
| Safe area | Full width, sin texto crítico en bordes (10px) |
| Fallback | background-color #F8F5FC en contenedor |

|---|---|
| Nombre | `icon-[nombre].png` |
| Ancho | 44px × 44px |
| Formato | PNG con transparencia |
| Peso máx. | 8 KB |
| Familia | Una sola familia visual (outline o filled, no mezclar) |

| Fondo opcional | #F3E5F5 (círculo lavanda) |

## Reglas generales

- PNG con transparencia real
- Sin bordes duplicados
- Sin sombras
- Sin texturas
- Sin degradados complejos
- Estilo plano vectorial
- Una sola familia visual por campaña
- No incluir texto crítico dentro del asset

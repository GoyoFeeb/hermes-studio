## 2. Objetivos de negocio

- **Objetivo principal**: Newsletter premium de conversión para Audi
- **Propósito**: Generar leads cualificados y solicitudes de prueba de conducción
- **Foco**: Transmitir deseo por la marca Audi, no promociones ni descuentos
- **Audi nunca comunica desde el descuento. Comunica desde el deseo.**
- La newsletter debe optimizar: CTR, calidad percibida, confianza, deseabilidad, lead generation
- No debe parecer diseñada para vender. Debe provocar que el usuario quiera saber más

## 3. Valores de marca a transmitir

### Sí transmitir
- Tecnología
- Precisión
- Ingeniería
- Lujo moderno
- Minimalismo
- Sofisticación
- Deportividad
- Confianza

### NO transmitir
- Agresividad comercial
- Promociones baratas
- Exceso de elementos
- Ruido visual
- Apariencia de ecommerce
- Apariencia de marketplace

## 4. Filosofía de diseño

**"The Radical Next"** — Reducir a lo esencial, priorizar la claridad, expresar precisión técnica y generar deseo mediante una estética refinada y contenida.

Cuatro principios rectores:
1. **Minimalismo** — nada que no tenga función clara
2. **Técnica** — precisión en cada elemento
3. **Inteligencia** — cada decisión tiene una razón
4. **Emoción** — generar deseo mediante la estética

## 5. Identidad visual detallada

### Paleta de color
| Color | Hex | Uso |
|---|---|---|
| Negro profundo | `#000000` | Fondos oscuros, texto principal, CTA |
| Blanco puro | `#FFFFFF` | Fondos claros, texto sobre oscuro |
| Gris muy claro | `#F5F5F5` | Fondos alternos |
| Gris claro | `#ECECEC` | Bordes sutiles |
| Gris medio | `#D9D9D9` | Separadores |
| Gris medio oscuro | `#666666` | Texto secundario |
| Gris oscuro | `#444444` | Texto terciario |
| Gris muy oscuro | `#222222` | Fondos oscuros alternos |

**Regla**: No utilizar colores llamativos. Los únicos colores vivos deben provenir del vehículo. Si existe un color de acento: usar únicamente pequeños detalles metálicos o el rojo RS cuando tenga sentido. Nunca utilizar colores saturados para botones. El protagonismo debe recaer en el coche.

### Fondos
- Predominio absoluto del blanco
- Alternancia con fondos gris muy claro
- Evitar degradados llamativos, fondos de color
- Los fondos deben generar aire

### Tipografía
- Sans serif premium, aspecto técnico
- Peso ligero predominantemente (Light, Regular, Medium)
- Muy poco Bold
- El tamaño debe crear elegancia, nunca sensación publicitaria

### Fotografía
- Las imágenes son el activo principal
- Calidad editorial, resolución máxima
- Luz natural, alto contraste controlado
- Fondos limpios, arquitectura moderna, paisajes minimalistas
- Superficies de hormigón, vidrio, metal, carreteras abiertas
- Cada fotografía debe parecer una campaña internacional de Audi

### Dirección de arte
- Sensación: arquitectura alemana, precisión, ingeniería, escultura, metal, volumen, líneas limpias, reflexiones controladas, equilibrio
- Nunca estética lifestyle exagerada

## 6. Estructura de la newsletter (patrón candidato)

Basado en el análisis de marca (a confirmar por agentes 02 y 03), el patrón candidato es `fotografia-primero`:

1. **Header** — Logo Audi centrado, fondo blanco
2. **Hero** — Fotografía a todo el ancho del vehículo (hero-imagen)
3. **Intro + CTA** (opcional) — Texto breve tipo editorial, CTA secundario
4. **Beneficios sin icono** (opcional) — 2-4 argumentos en columnas iguales
5. **Banda de cierre** — CTA principal, copy de cierre
6. **Footer** — Datos legales de Audi

## 7. Copy y tono

### Tono
- Corto, elegante, seguro
- Nunca agresivo, nunca promocional
- Hablar desde: innovación, tecnología, prestaciones, diseño, experiencia, progreso

### Prohibido
- "Gran oferta"
- "No te lo pierdas"
- "Última oportunidad"
- "Sólo hoy"
- Cualquier expresión de urgencia o descuento no verificada

### CTAs sugeridos
1. Solicitar oferta personalizada
2. Reservar prueba de conducción
3. Descubrir el modelo
4. Configurar mi Audi

## 8. CTAs y conversión

### Botones
- Discretos, mucho espacio
- Negro sobre blanco O blanco sobre negro
- Sin sombras, sin degradados, sin efectos
- Sin bordes redondeados excesivos (radio mínimo)

## 9. Requisitos técnicos

- HTML compatible con: React Email, Outlook, Gmail, Apple Mail
- Dark Mode soportado
- Responsive perfecto
- Sin hacks visuales
- Sin dependencias innecesarias
- VML para botones en Outlook
- CSS inline
- Sin JavaScript
- Dimensiones explícitas en imágenes
- Alt text en todas las imágenes

# Visual Analysis — Audi A6 Sportback e-tron

## Colores (observados de audi.es, getComputedStyle)
- **Primary / Text**: #000000 (negro absoluto)
- **CTA Background**: #000000 (botones negros)
- **CTA Text**: #FFFFFF (texto blanco sobre botón negro)
- **CTA Hover**: #1a1a1a
- **Surface white**: #FCFCFD (off-white)
- **Deep/dark**: #101319 (fondo oscuro de cierre)
- **Secondary text**: #67707F (gris técnico)
- **Section bg**: #F5F5F5 (gris claro para fondos de sección)
- **On brand secondary**: #ABB1C3

## Tipografía
- **Web**: AudiType (propietaria de Audi AG)
- **Email fallback**: Arial, Helvetica, sans-serif
- **Web font alternativo**: Inter (geométrico, same character as AudiType)
- **Hero H1**: 32px/300 weight/1.15 line-height, blanco
- **Hero subtitle**: 16px/400 weight
- **Section H2**: 22px/400 weight (light/regular)
- **Body**: 14px/400 weight/1.5 line-height
- **CTA**: 16px/500 weight, letter-spacing 1px

## Botones / CTA
- **Forma**: Pastilla sólida negra (border-radius: 0)
- **Padding**: 16px 36px
- **Texto**: blanco, 16px/500, letter-spacing 1px
- **Estilo**: minimalista, sin bordes redondeados, sin sombras

## Composición
- Centrada, simétrica, minimalista
- Sin decoración lateral
- Fotografía como único adorno visual
- Sin iconos, sin emoji, sin gradientes

## Ritmo estructural
- La página del A6 Sportback e-tron alterna fotografía gran formato → datos → editorial foto+texto → datos → cierre
- La fotografía ocupa ~70% del espacio visual
- El texto es siempre mínimo: titular corto + 1 párrafo
- El email debe respetar esta proporción: foto grande, texto breve, sin relleno
